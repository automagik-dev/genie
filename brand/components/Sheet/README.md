# Sheet

The download sheet a platform chip opens: what you get, the exact file, what it needs, how to install it, and one primary button.

- A `paper` dialog with the `st-r-dialog` corner and a `line-2` border, at most 580px wide, centred on the page.
- Order: the platform's sign and name, one sentence, the facts, the numbered steps, then the download.
- On the site it is a browser popover: Escape and a click outside close it.
