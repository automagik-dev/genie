# Menu

The panel a header menu opens: a `paper` card with a list of destinations and a quiet foot line.

- Each item has an icon in a soft square, a bold name and one line of plain text.
- The card has a 24px corner, a `line-2` border and the `shadow-window` shadow.
- On the site it opens through the browser's own popover, under the header, as wide as the page content (`max`).
