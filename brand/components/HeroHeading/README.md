# HeroHeading

The top of a product page: an eyebrow, the page title, one intro line, the actions, and a line of fine print.

- Eyebrow: `label-eyebrow`, capitals, in `ring`. Title: `heading-1`. Intro: `text-intro`. Fine print: `text-fine` in `muted`.
- At most two buttons: one primary, one secondary.
- Inline code sits on a `bt-hover` wash with a `line` border.
