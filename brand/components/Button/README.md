# Button

Two buttons. **Primary** is flat ink (`text`) with `bg`-coloured words and a soft press: one per view, for the thing the page is for. **Secondary** is `paper` with a `line-2` border.

- Text is `label-button`: verb first, sentence case ("Get the app", "Read the docs").
- 52px high with a 14px corner; `small` is 40px with a 12px corner, for the header.
- An arrow after the words says where it goes: → the next page, ↗ another site, ↓ a download.
- Focus shows the `ring` outline, 3px, 3px off the edge.
