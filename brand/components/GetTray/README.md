# GetTray

"Get Automagik for": a row of platform chips. A live platform is a button that opens its Sheet; a platform that is not ready yet is shown as text with a "soon" mark, never as a dead button.

- Each chip has the platform's sign, its name and the file kind (`.dmg`, `.deb`, `.apk`).
- The platform signs are the platforms' own; do not restyle them.
