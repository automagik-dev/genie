# Footer

The site's footer: the logo with one line about the product, three columns of links, and the licence line. It sits on `raised` with a `line` on top.

- The logo is the same lockup as in the header, a little larger (shown 37px high).
- Column heads use `label-small` in `muted`. Links are plain text; the current page is bold.
- On the site the last row ends with the Open Intelligence tag. That tag is we unfold's mark, not part of this system: take it from the site's own files, at 170 by 32px, and never redraw or recolour it.
