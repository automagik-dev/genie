# Probe artifact — Claude Code stdio MCP server cwd (Risk 2)

Recorded 2026-07-26 per design-review rcp-03 P2, so the Risk 2 Medium→Low
downgrade stays auditable after the observed processes exit.

- **Host:** this machine (Ryzen AI station), Linux 7.0.0-28-generic
- **Claude Code version:** 2.1.220
- **Registration probed:** user-scope stdio server
  (`claude mcp add rlmx --scope user -- node /home/namastex/prod/rlmx/dist/src/cli.js mcp`)
- **Observation** (`readlink /proc/<pid>/cwd`, 2026-07-26):

  | pid | cwd | parent |
  |---|---|---|
  | 2457829 | `/home/namastex/workspace` | `claude --dangerously-skip-permissions` |
  | 2574043 | `/home/namastex/workspace` | `claude --dangerously-skip-permissions` |

  Both sessions were running in `/home/namastex/workspace`; the servers'
  cwd matched the session project directory in both cases.

- **Conclusion:** Claude Code 2.1.220 spawns user-scoped stdio MCP servers
  with cwd = the session's project directory, so bare registration supports
  workspace-first agent discovery on this host. The `--dir` flag (D10)
  remains the explicit contract for other hosts (Codex, Hermes) and for any
  future Claude Code behavior change.
- **Transience note:** these processes end with their sessions; rcp-03 could
