Deliver explicit RLM and protocol-free Pi engines, bounded RLM reliability repairs, Genie proposal-only NEW verification and workflow engine selection. Preserve Mikro history as an independently gated Genie subtree, add explicitly configured Juice project keys/usage and manual Keeper/JEV extraction, and compare actual success/cost/latency on frozen parent-tree cases and real wish variants. ## Decisions

| # | Decision | Rationale |
|---|----------|-----------|
| 1 | Owner's end-to-end choice controls all implementation and experiment obligations | Design readiness is not delivery |
| 2 | RLM default; explicit Pi opt-in and strict call > agent > default precedence | No hidden shape heuristic or silent fallback |
| 3 | Exact SDK family 1.0.2 and isolated read-only Pi session | Avoid duplicate provider identities and ambient tool/auth/resource loading |
| 4 | Timeout restart discards Python variables and never replays timed-out code | SIGKILL cannot preserve state; replay can duplicate side effects |
| 5 | Last model turn finalizes inside declared limits | No unbounded extra completion outside the cap |
| 6 | Non-squash subtree; independent npm/Node gates and CI | Keep history, ownership and unchanged Genie binary/tarball payload |
| 7 | Flash control; curated models separately reported; no Pro/Claude calls | Owner explicitly superseded the earlier Pro comparison |
| 8 | Keeper viewer aggregates and separate manual JEV selection | Project-key authorization does not include request/conversation exports |
| 9 | Observe native workflow UUID/seq/child sessions and measured usage | Existing DSH success journals alone cannot prove report-compatible accounting |

## Simplicity Case

- **Simplest complete design:** reuse RuntimeBackend, Pi's supported tool loop, existing Genie verifier/ledger/report consumers and existing DSH saved-workflow runner; one delivery branch with one independent Mikro package.
- **Added machinery:** scoped SDK resources/tools protect read-only boundaries; typed timeout recovery prevents a dead namespace; parent-tree fixtures remove answer leakage; private project-key storage enables requested attribution; a small experiment-local native event observer supplies actual stage identities/usage without changing consumers.
- **Deferred until measured:** routing, schedules, extra retry layers, caches, compaction and Prime upgrades require separate evidence/approval.
- **Complexity removed:** hidden backend alias, Pi REPL protocol, forced final outside cap, global provider mutation, duplicate accounting stores, submodule and Genie bundling.
