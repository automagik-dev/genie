# A brainstorm round without a workflow surface

The same spine `brainstorm.js` runs, done inline by the session that loaded the skill, one round per turn: the owner answers between turns. `L` below is `node "<brainstorm-skill-dir>/references/round-ledger.mjs"` and `D` is `.genie/brainstorms/<slug>/DRAFT.md`. Every ledger call prints one JSON object and exits 0 (ok), 1 (a refusal or blocking findings) or 2 (usage); any JSON flag takes `@<file>`, so a question text never has to survive shell quoting. The ledger is the only writer of the fenced `ledger` block and of the sections `## Settled`, `## Asked`, `## Size`, `## Scope ratchet` and `## Councils`: never edit them by hand.

## One round

1. **Apply.** `L apply --draft D --answers @answers.json`, with the answers of the last round as `[{id, question, answer}]`, or no `--answers` on the first round, which creates the DRAFT. Keep the `round` it returns and pass it as `--round` to every later call of this round. A refusal names the answer it refused; relay it, because only the owner can resolve it.
2. **Lead.** Read the DRAFT in full. On round 1 write what the owner said against what you assume, and the size triage: P, M or G, and whether it splits. Every round write the WRS bar (five dimensions × 20: Problem, Scope, Decisions, Risks, Criteria, each with its evidence), the gap map (settled, open, what blocks what), and the Open and Assumed sections. A load-bearing assumption becomes a question, never a silent decision.
3. **Scouts.** A fact the repository or a source can answer is the round's to find, never the owner's to supply: send each one to a read-only scout through the native delegation surface, none when what you have answers the round.
4. **Council.** Convene the Socratic council only when the owner asked or one decision is contested and hard to reverse, and never in a round with scouts. Read the count from `councils` in apply's output. Past `councilCeiling` (`genie config get budgets.maxCouncilsPerBrainstorm`, default 1) convene only on a Settled, unused `council-approval` answer whose value is `convene`; otherwise ask that question; never past 3, and at 3 ask nothing. Write 3 to 5 lens briefs for the decision, one of them dissent; each lens answers alone, Socrates questions every lens, each answers, and Socrates decides, numbering decisions after the existing `P<n>`. Record it: `L council --draft D --round N --run <id> --ceiling <c> [--approved <id>] --decided '["P4"]'`.
5. **Questions.** At most four, each one decision only the owner can make, with 2 to 4 options: the recommended first with a label ending "(Recommended)", the trade-off or the dissent in each description, a header of at most 12 characters, and a stable value per option. A reopen question names the Settled id in `reopens` and quotes the old answer, then → and the new one. A smaller size or a dropped Scope IN item is a question whose agreeing option has the value `size:<P|M|G>` or `scope-drop:<item>`; ending without a design is a question of kind `end-without-design` with an option valued `end`. Record them with `L ask --draft D --round N --questions @questions.json`, which assigns the ids `R<round>-<n>`.
6. **Ratchet and render.** `L ratchet --draft D --round N --by <who> --size <P|M|G> --scope @scope.json` records a raise (the scope is the WHOLE Scope IN list); then `L render --draft D`.
7. **Ask.** Show each question as numbered options with its id; the owner answers by number or in their own words. The next turn applies those answers as step 1.

## Crystallize

At WRS 100 with nothing open, write `.genie/brainstorms/<slug>/DESIGN.md` from `design-template.md`, keeping its headings, and run `L check-design --design .genie/brainstorms/<slug>/DESIGN.md --draft D`. Blocking findings become one owner question instead of a review. Otherwise send the design to an independent reviewer as SKILL.md says, stamp the verdict it returns, and record it with `L review --draft D --round N --verdict <SHIP|FIX-FIRST|BLOCKED> --digest <reviewed-sha256> [--repaired] --findings '["HIGH-1"]'`. A FIX-FIRST gets one repair and a fresh review per turn while `repairBudget` (`genie config get budgets.maxEscalationsPerGroup`, default 2) lasts; then ask a `review-findings` question with the options repair again (Recommended), I settle them, stop. SHIP freezes DESIGN.md.

Report the same states as the workflow: `round`, `done` (a verified SHIP stamp, the only route to `wish`), `answered`, `blocked` and `failed`.
